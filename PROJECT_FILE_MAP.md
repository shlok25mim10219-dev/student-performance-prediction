# Project File Map

## Executable
- `main.py` — command-line entry point and argument handling.
- `run_cli.bat` — Windows launcher.

## Source modules
- `src/config.py` — paths, feature names and validation limits.
- `src/data_loader.py` — CSV loading and feature mapping.
- `src/regression.py` — ordinary least-squares Multiple Linear Regression, prediction and metrics.
- `src/academic.py` — academic contribution and eligibility calculations.
- `src/analysis.py` — validation and recommendations.
- `src/reporting.py` — terminal output/reporting.
- `src/app.py` — interactive and example application flow.

## Data
- `data/vit_student_dataset.csv` — 240 simulated academic records.

## Documentation
- `README.md` — setup, execution and project overview.
- `statement.md` — problem, scope, users and high-level features.
- `TESTING.md` — testing strategy and expected results.
- `CLI_EXECUTION.md` — command-line execution guide.
- `PROJECT_REPORT_CONTENT.md` — report source content.
- `SUBMISSION_CHECKLIST.md` — final submission checklist.

The curriculum reference used during development is not included in the GitHub submission package at the user's request.
