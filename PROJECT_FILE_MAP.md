# Project File Map

## Application
- `run_cli.bat` — Windows shortcut for the terminal application.
- `main.py` — command-line application and core terminal workflow.

## Data
- `data/vit_student_dataset.csv` — 240 simulated student/course records.

## Documentation
- `README.md` — overview, features, setup and terminal execution instructions.
- `statement.md` — problem statement, scope, target users and features.
- `PROJECT_REPORT_CONTENT.md` — report content.
- `CLI_EXECUTION.md` — command-line execution and evaluator quick test.
- `TESTING.md` — project validation/test matrix.
- `SUBMISSION_CHECKLIST.md` — final submission checklist.
- `Curriculum_MTech_2026.pdf` — supplied curriculum source.

## CLI validation
`python main.py --test` performs dataset-count, regression-metric and academic-calculation assertions.
