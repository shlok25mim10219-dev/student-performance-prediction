# Project Workflow

1. Start the terminal application.
2. Load 240 simulated academic records.
3. Validate input ranges.
4. Split records into 80% training and 20% testing.
5. Fit Multiple Linear Regression on the training set.
6. Predict the student's final score.
7. Calculate weighted academic contributions.
8. Check attendance, TEE and raw-score conditions.
9. Generate a recommendation.
10. Report MAE, RMSE, R² and baseline MAE.
