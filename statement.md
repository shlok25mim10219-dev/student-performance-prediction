# Project Statement

## Title
Student Performance Prediction and Academic Analysis using Multiple Linear Regression

## Problem
Students often have academic information spread across attendance, continuous assessment, internal tests and examination marks. A lightweight analysis tool can combine these indicators, estimate performance and identify academic conditions requiring attention.

## Scope
The project is an educational AI/ML prototype. It predicts a final score from academic indicators using Multiple Linear Regression and performs a separate academic calculation and eligibility analysis.

## Target users
- Students
- Academic project evaluators
- Learners studying introductory AI/ML workflows

## High-level functional modules
- Data loading and validation
- Multiple Linear Regression training
- Model evaluation
- Student score prediction
- Academic score calculation
- Eligibility/pass analysis
- Recommendation generation
- Interactive and command-line execution

## Dataset
The repository contains 240 simulated records. The data is synthetic and is included only for educational demonstration.

## Model
Ordinary least-squares Multiple Linear Regression with seven academic features and final score as the target.

## Evaluation
The supplied 240 records are divided using an 80/20 split: 192 training records and 48 test records.

## Important note
The prediction is a prototype estimate. It is not an official university result and should not be used for academic decision-making.
