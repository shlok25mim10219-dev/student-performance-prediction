# Command-Line Execution

The project is a terminal-only application. `main.py` is self-contained and uses Python standard-library modules only.

## Evaluator quick test

```bash
python main.py --test
python main.py --metrics
python main.py --example
```

Expected test output includes:

```text
All CLI validation tests passed.
```

The CLI implements the same core project concepts: dataset loading, Multiple Linear Regression, model evaluation, academic calculation, attendance/pass analysis and recommendations.

The included dataset is simulated and is not official VIT student data.
